💾 BACKUP YOUR DATA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IMPORTANT: Data is stored in your browser!

To backup:
1. Go to Settings tab
2. Click "Export Data (CSV)"
3. Save the file somewhere safe

⚠️  Clearing browser data will delete workouts!
    Export regularly to be safe.

🏋️ EXAMPLE WORKOUT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Click "Start Empty Workout"
2. Name it "Chest Day"
3. Click "Add Exercise"
4. Select "Barbell Bench Press"
5. Click "Add Set"
6. Enter weight: 135 lbs, reps: 10
7. Click checkmark when done
8. Rest timer starts automatically
9. Add more sets
10. Add more exercises
11. Click "Finish Workout"

Done! Your workout is saved.

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Page won't load
Solution: Enable JavaScript in browser

Problem: Data disappeared
Solution: Check if browser cleared storage
         Look for CSV backup files

Problem: Can't export data
Solution: Allow downloads in browser settings

Problem: Looks broken
Solution: Use modern browser (Chrome, Firefox, Safari)
